# 動画と公開ノート

- 元教材は引き続きLearning OSの非公開の学習用Markdown。公開ノートは動画から復習するための独自編集版。
- 対応表は `sources/video-notes.json`。公開済みの対応ノートが未登録なら `memory:prepare` は停止する。
- 概要欄の先頭に公開ノートの直接URLを自動挿入する。
- ノート本文にも既存動画へのリンクを掲載する。動画公開状態は別に管理し、再アップロードしない。
